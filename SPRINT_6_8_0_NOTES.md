# Sprint 6.8.0 — Media Engine Foundation

This sprint introduces the renderer-agnostic media project model used between AI output and future render adapters.

## Added
- Millisecond timeline and scene planning
- Speech-duration estimation with explicit-duration support
- Asset resolver contract and default resolver
- Multi-track composition model
- Versioned render manifest
- Media engine registered in the dependency container
- Media project Zustand store
- Typed media lifecycle events

## Scope
This sprint builds render-ready data. It does not encode or export a video yet.
